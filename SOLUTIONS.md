# Solutions

Repositories built by people working through the challenges. Browsing them is a
good way to see how differently the same spec can be satisfied.

Want yours here? Open a
[Submit your solution](https://github.com/micheltlutz/dev-challenge/issues/new/choose)
issue.

## What gets listed

Anything that genuinely attempts a challenge. There is no bar, no score and no
ranking — the harness reports which criteria pass, and that is between you and
your own repo.

We do ask for:

- A public repository with a README saying how to run it.
- Which challenges you attempted.
- Your stack.
